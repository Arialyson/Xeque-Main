# ♟️ Xeque-Mate Controle de Pragas — Website Institutional

Este repositório contém o código-fonte da landing page institucional da **Xeque-Mate Controle de Pragas**. O site foi desenvolvido para apresentar os serviços de dedetização e controle de pragas urbanas, a história da empresa, além de fornecer um canal direto de contato e orçamento via WhatsApp e redes sociais.

## 🏢 Sobre a Empresa

A **Xeque-Mate Controle de Pragas** oferece soluções eficazes, seguras e acessíveis no combate a pragas urbanas. Com atuação em residências, condomínios, comércios e indústrias, a empresa prioriza a segurança das pessoas, dos animais de estimação e do meio ambiente.

**Serviços oferecidos:**
- Controle de baratas, formigas e escorpiões
- Descupinização e Desratização
- Controle de moscas e caramujos
- Sanitização / Desinsetização
- Monitoramento preventivo

---

## 🚀 Funcionalidades do Site

- **Hero Section (Início):** Apresentação com efeito de digitação (*typewriter*) e botão de ação rápida para orçamento no WhatsApp.
- **Sobre a Xeque-Mate:** Seção detalhando a história, missão e diferencial competitivo da empresa.
- **Controle de Pragas:** Vitrine interativa direcionada para páginas específicas de cada tipo de praga (Escorpiões, Roedores, Aranhas, Baratas, Formigas, Moscas).
- **Serviços:** Seção com ícones interativos representando os ambientes atendidos (Casas, Condomínios, Comércios, Indústrias, Limpeza, etc.).
- **Navegação Responsiva:** Menu dinâmico adaptado para dispositivos móveis com suporte a *scroll smooth*.
- **Integração Social:** Links rápidos para Instagram, Facebook e WhatsApp.

## 📁 Estrutura do Projeto

```text
.
├── index.html                  # Página principal

├── LICENSE                     # Licença do projeto (MIT)

│   ├── sobre-mim.css           # Seção sobre a empresa
```

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização responsiva com Flexbox, Grid, Animações CSS e CSS Variables.
- **JavaScript (ES6+):** Lógica de animações e interações dinâmicas.
- **Google Fonts:** Tipografias *Roboto*, *Quando* e *Press Start 2P*.
- **ScrollReveal.js:** Bibliotecas externas para efeitos de scroll.
